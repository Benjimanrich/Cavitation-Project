# Cavitation-Project
Files and Data for my cavitation course group project
The code in this repository was generated by an LLM


The data and screenshot is from Hoeppe, H. P., et al. (2024). “The collapse of a sonoluminescent cavitation bubble imaged with X-ray free-electron laser pulses.” New Journal of Physics, 26, 033002.
[DOI: 10.1088/1367-2630/ad295b](https://doi.org/10.1088/1367-2630/ad295b)


code and generated plots are in the code folder, data and other related files(including fiji macros and methodology) are in the data folder
